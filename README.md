# Employee Attrition Analysis Using Probability & Statistics

## Overview
This project analyzes employee attrition using statistical and analytical techniques to identify factors associated with employees leaving an organization. The analysis is performed on an HR dataset containing 1,470 employee records.

## Objectives
- Analyze attrition patterns across employee demographics and workplace factors.
- Examine relationships between attrition and variables such as department, age, gender, income, job satisfaction, overtime, and tenure.
- Apply statistical tests to determine significant associations and differences.
- Identify factors associated with employee attrition using logistic regression.

## Methods Used
- Descriptive Statistics
- Exploratory Data Analysis (EDA)
- Chi-Square Test
- Independent Samples t-Test
- Correlation Analysis
- Logistic Regression
- Data Visualization

## Key Insights
- Younger employees showed a comparatively higher attrition rate.
- Attrition rates varied significantly across departments.
- Employees who left had a lower average monthly income than employees who stayed.
- Overtime showed a strong positive association with employee attrition.
- Job satisfaction, income, and organizational tenure showed negative relationships with attrition in the regression analysis.
